# باك إند بنك أسئلة التمييز

## الوظائف الموجودة

- تسجيل بيانات الطالب للصفوف 1–10 والتحقق من رقم الهاتف.
- تخزين الطلاب والجلسات والمواد والامتحانات والأسئلة والمحاولات والنتائج في PostgreSQL.
- تصحيح الإجابات على الخادم؛ مفتاح الإجابة لا يُرسل للطالب.
- لوحة إدارة على `/admin.html` لمراجعة الطلاب والنتائج وتصدير CSV واستيراد نماذج الأسئلة.
- كل نموذج مستورد يحتوي 15 سؤالاً، ورقم النموذج من 1 إلى 3 لكل صف ومادة وفصل.

## تجهيز Netlify

هذا مشروع Netlify كامل: الملفات العامة في `public/`، والـ Functions خارجها في `netlify/functions/`. يقرأ Netlify ملفات SQL من `netlify/database/migrations/` ويطبقها ضمن دورة النشر.

1. اربط المشروع بمستودع Git أو انشره من Netlify CLI / API مع تشغيل البناء. النشر بالسحب والإفلات ينشر ملفات ثابتة فقط ولا يبني Functions أو قاعدة البيانات.
2. أضف حزمة `@netlify/database` ثم نفّذ نشر Netlify لإعداد PostgreSQL وتطبيق migrations.
3. أضف متغيرات البيئة التالية ضمن نطاق Functions، ولا تضع قيمها داخل الملفات:
   - `OTP_SECRET`: قيمة عشوائية طويلة لحماية رموز التحقق المخزنة.
   - `ADMIN_PASSWORD`: كلمة مرور قوية للوحة `/admin.html`.
   - حالياً يعمل رمز تجريبي ثابت `1223456` دون إرسال SMS، ويظهر للطالب على شاشة التسجيل. هذا إعداد مؤقت ويجب استبداله بمزوّد رسائل قبل استخدام التسجيل الفعلي.
4. قبل إطلاق التسجيل الفعلي، استبدل رمز التجربة الثابت بآلية تحقق آمنة مرتبطة بمزوّد SMS.

## استيراد الامتحانات

افتح لوحة الإدارة، سجّل الدخول، وحمّل ملف JSON وفق `import-template.json`. لكل نموذج: الصف، المادة، الفصل، رقم النموذج (1–3)، و15 سؤال اختيار من متعدد بأربعة خيارات وفهرس للإجابة الصحيحة يبدأ من صفر. تنشأ المواد والنماذج تلقائياً عند الاستيراد.

## محتوى المنهاج الأردني

مصدر الكتب المعتمد هو المركز الوطني لتطوير المناهج: https://nccd.gov.jo/Ar/Pages/textbooks . راجع طبعة العام الدراسي والصف والمبحث قبل إعداد الأسئلة. المحتوى الرسمي متاح للمطالعة من مصدره؛ لا تعِد نشر ملفات الكتب أو نسخ نصوصها داخل البنك دون إذن أصحاب الحقوق. أنشئ أسئلة أصلية تقيس نتاجات التعلم، وراجعها أكاديمياً قبل النشر.

## التسعير

قاعدة Netlify تستهلك أرصدة بحسب استخدام الحوسبة وحركة البيانات، بحسب الخطة. قاعدة البيانات لم تُفعّل من هذا المصدر؛ يلزم ربط المشروع بعملية نشر Netlify كاملة أولاً.
